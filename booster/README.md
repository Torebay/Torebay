# PingBoost: игровой бустер для PUBG Mobile (Android)

Личный аналог LagoFast Mobile. Пускает через твой сервер **только трафик PUBG Mobile** (остальные
приложения работают напрямую), показывает пинг, потери и джиттер в реальном времени и сам выбирает
сервер с лучшим пингом.

## Что умеет (версия 0.1)

| | |
|---|---|
| Ускорение только для игры | Через туннель идёт только PUBG Mobile (Global, Lite, Корея, Вьетнам, Тайвань, BGMI, New State). Мессенджеры, браузер, YouTube не затрагиваются |
| Несколько серверов | Добавляешь свои серверы (Россия, Финляндия, Германия, Нидерланды…), на каждом свой конфиг |
| Авто-выбор | Перед запуском замеряет все серверы и берёт лучший по формуле: пинг + 2 × джиттер + 10 × % потерь |
| Живая статистика | Пинг, потери, джиттер, график за минуту, объём трафика через туннель |
| Работа в фоне | Туннель остаётся включённым, когда ты закрыл окно приложения и играешь |

Пока **нет** (задумано на следующие версии): чистка RAM, режим «не беспокоить», пинг поверх игры
(оверлей), другие игры, VLESS/Shadowsocks, сканер QR.

## Как это работает, и честно о пределах

```
Телефон ──WireGuard (UDP, шифрование)──► твой сервер (Германия…) ──► серверы PUBG
          только пакеты PUBG Mobile
```

Приложение **не снижает пинг само по себе**. Выигрыш бывает, когда маршрут «телефон → твой сервер →
сервер игры» лучше, чем прямой маршрут от твоего провайдера. Типичные случаи: провайдер плохо
маршрутизирует до игры, теряет пакеты, режет скорость на каком-то направлении. Если у тебя и так
хороший пинг напрямую, ускоритель может только добавить пару мс. Поэтому:

- пинг на главном экране = путь **до твоего сервера**, до самой игры он чуть больше;
- смотри на ощущения и на ping в самой игре (в PUBG он виден в лобби и в матче), сравни с включённым
  и выключенным ускорением и оставь то, что лучше;
- выбирай сервер, который **ближе к серверам PUBG твоего региона** (для Европы это обычно
  Германия или Нидерланды, проверь пингом в игре), а не просто ближе к тебе.

Про бан-риски: ускоритель не меняет игру и не читает её память, это обычный VPN, но Tencent
не гарантирует отсутствие дополнительных проверок. Если у тебя на аккаунте важный прогресс и при
входе с другой страны игра просит подтверждение, это нормально. Держись одного сервера, не прыгай
между странами каждый матч.

## Шаг 1. Серверы

Приложение говорит на **WireGuard**, а не на VLESS/Shadowsocks/OpenVPN. Если на твоих серверах уже
работает VPN другого типа, ничего страшного: скрипт ниже ставит WireGuard **рядом**, на отдельном
порту и в отдельной подсети, и существующее не трогает.

Нужен VPS на **Ubuntu или Debian** с виртуализацией KVM (на OpenVZ/LXC нет модуля WireGuard).

На каждом сервере (по SSH, от root):

Скопируй файл `booster/server/pingboost.sh` на сервер (например, `scp booster/server/pingboost.sh root@IP:/root/`
или вставь содержимое в `nano pingboost.sh`) и запусти:

```bash
SERVER_NAME="Германия" sudo -E bash pingboost.sh install
```

Скрипт поставит WireGuard и маленькую UDP-службу для замера пинга, включит пересылку пакетов и в конце
напечатает **конфиг**. Его и нужно скопировать в приложение. Дополнительно:

- **Открой UDP-порты 51830 и 51831** в файрволе или панели хостинга (скрипт сам открывает их только в
  `ufw`). Без порта 51831 приложение покажет «нет ответа», без 51830 туннель не поднимется.
- Занято? Задай другие порты: `WG_PORT=51840 PING_PORT=51841 SERVER_NAME=… sudo -E bash pingboost.sh install`.
- Ещё один телефон или ещё один конфиг: `sudo pingboost add-client tablet Германия`.
- Показать конфиг ещё раз: `sudo pingboost show phone`. Список и состояние: `pingboost list`, `pingboost status`.
- Убрать доступ: `sudo pingboost remove-client phone`.

Повтори на каждом сервере, поменяв `SERVER_NAME` (Финляндия, Нидерланды, Россия…). Название потом
можно изменить и в приложении при добавлении.

## Шаг 2. Получить приложение (APK)

APK собирает GitHub:

1. Открой репозиторий на github.com → вкладка **Actions** → слева **PingBoost Android build**.
2. Выбери последний зелёный запуск → внизу в разделе **Artifacts** скачай **PingBoost-debug-apk**.
3. Распакуй zip, скинь `app-debug.apk` на телефон, открой. Android спросит разрешение на установку
   из неизвестных источников, разреши.

(Сборка локально: открой папку `booster/android` в Android Studio или выполни `./gradlew :app:assembleDebug`.)

## Шаг 3. Пользоваться

1. Вкладка **Серверы** → **Добавить сервер** → **Вставить** (конфиг со скриншота/из заметок) → **Добавить**.
   Рядом с каждым сервером появится пинг и потери. Если «нет ответа по UDP 51831», порт закрыт в файрволе.
2. Вкладка **Главная** → большая кнопка. При первом запуске Android спросит «Разрешить PingBoost
   создавать VPN-подключение», это нормально, так работают все бустеры.
3. Запускай PUBG Mobile. Пока кнопка зелёная, игра идёт через сервер.
4. В **Настройках** нажми «Открыть настройки батареи» и разреши приложению работать без ограничений,
   иначе Xiaomi/Samsung/Huawei могут убить туннель посреди матча.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| «нет ответа по UDP 51831» | Порт закрыт в файрволе/панели хостинга; `sudo systemctl status pingboost-echo` на сервере |
| «Не удалось подключиться» | Порт 51830/udp закрыт; конфиг скопирован не полностью; на сервере `sudo wg show` |
| Подключилось, но в игре нет сети | `sysctl net.ipv4.ip_forward` должен быть 1; смотри правила `iptables -t nat -L POSTROUTING` |
| «PUBG Mobile не найден» | Игра не установлена или версия не отмечена в Настройках |
| Пинг в игре хуже, чем без ускорителя | Выбери другой сервер, ближе к серверам игры, или выключи ускорение |
| Туннель сам отключается | Отключи оптимизацию батареи (Настройки приложения) |

## Что внутри

```
booster/
  android/
    core/     логика без Android: замер пинга по UDP, статистика, выбор сервера, разбор конфига (с тестами)
    app/      приложение на Kotlin + Jetpack Compose; туннель — официальная библиотека WireGuard (GoBackend)
  server/
    pingboost.sh   установка WireGuard + службы пинга на VPS, управление клиентами
```

- Приватные ключи лежат только в приватной папке приложения, облачная копия Android отключена.
- В туннель попадают только приложения из `IncludedApplications`. Приложение **подменяет** этот список
  своим, даже если в импортированном конфиге он был.
- IPv6 в конфиге не включён намеренно: игра ходит по IPv4, а при `::/0` без пересылки IPv6 на сервере
  UDP-пакеты игры терялись бы молча.
- Тесты ядра: `cd booster/android && ./gradlew :core:test`.
