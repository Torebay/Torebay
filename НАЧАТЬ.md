# Kartal — командный центр

Дважды нажмите ярлык **Kartal** на рабочем столе или **Запуск.bat** в этой папке.

## Что работает без ключей

- Ввод команды внизу окна и кнопки быстрых команд.
- «который час», «какое сегодня число», «открой телеграм», «открой документы».
- «найди файл отчёт», «сделай тише», «сделай громче».
- «посчитай (120 + 30) * 2» — арифметика без отправки в интернет.
- Кнопка микрофона: нажмите и произнесите команду. Для распознавания используется Google, нужен интернет.
- Голос Windows. Интернет-голос Edge временно не выбран: при проверке сервис не вернул аудио.

## Gemini и OpenAI

1. Откройте **Настройки ИИ** в меню окна.
2. Для Gemini получите ключ на https://aistudio.google.com/api-keys.
3. Для OpenAI получите ключ на https://platform.openai.com/api-keys.
4. Вставьте ключ на соответствующей вкладке, нажмите **Загрузить модели** и выберите доступную модель.
5. Выберите отвечающий сервис и сохраните. Можно хранить оба ключа и переключаться.

Ключи хранятся зашифрованными средствами Windows в `%LOCALAPPDATA%\Kartal\keys.json`, отдельно от проекта. Они не входят в APK и исходники. Claude в запуске этой версии не используется.

## Чёткий голос и задержки

В настройках выберите **Голос → OpenAI**, затем **cedar** или **marin**. Нужен сохранённый ключ OpenAI, даже если на вопросы отвечает Gemini. Это синтетический голос с отдельным расходом API. Команда **«проверь голос»** произнесёт тестовую фразу.

Ответы Gemini/OpenAI принимаются потоком и передаются в озвучивание по предложениям. Нейроголос OpenAI воспроизводится по мере получения звука. Это убирает ожидание всего ответа и всего аудиофайла; задержка сервиса, поиска и интернета всё равно остаётся. Реальная скорость и качество на ваших ключах требуют проверки.

Без ключа или при недоступности нейроголоса используется системный голос. На Android такой же переключатель находится в настройках. Для обновления уже открытой ПК-версии после изменений кода сохраните настройки, закройте и вновь откройте Kartal.

Если нужен поиск свежей погоды, курсов и новостей, включите поиск ИИ. Выбранная модель должна поддерживать встроенный поиск. Проверяйте дату данных и источники в полном диалоге. Использование API и поиска зависит от квот, доступа и оплаты в аккаунте сервиса. Проверка реальных ответов требует ваших ключей.

## Файлы и история

**Файл для ИИ** позволяет выбрать небольшой UTF-8 файл TXT, MD, CSV, JSON, PY или LOG, указать задачу и передать его текст выбранному сервису. Предел — 150 КБ. DOCX, PDF и Excel пока не поддерживаются этим пунктом.

**Полный диалог** показывает полный ответ и источники; его можно сохранить в TXT. История запросов к ИИ сохраняется в `memory.json`. Команда «забудь разговор» очищает историю ИИ.

Локальные команды управляют только перечисленными функциями. Свободный запрос к ИИ не запускает произвольные программы, не изменяет файлы и не выполняет финансовые сделки. Автоматическая торговля не реализована.

## Android

Исходный код находится в `android`. Мобильный интерфейс использует тот же зелёный глобус и панели, с прокруткой под размер телефона. Подключение Gemini/OpenAI находится в настройках; ключи шифруются Android Keystore. Голос слушает, пока приложение на экране. Фоновое прослушивание не реализовано.

## Если что-то не запускается

Журнал ПК: `%LOCALAPPDATA%\Kartal\startup.log`.
Для работы без микрофона можно запустить `Запуск.bat --text`.

Папка `Jarvis` рядом — прежняя версия. Рабочая версия с изменениями находится здесь, в `Kartal-PC`.
