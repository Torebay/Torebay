# Kartal — Windows и Android

Зелёный командный центр с глобусом, голосовым и текстовым вводом.
Подключение **Gemini или OpenAI** выбирается в настройках. Ключи можно добавить позже.

## Запуск Windows

На настроенном компьютере: ярлык **Kartal** на рабочем столе или **Запуск.bat**.
Для другой установки: Python 3.10+, `python -m pip install -r requirements.txt`, затем `python -m assistant.main`.
Текстовый режим окна: `python -m assistant.main --text`.

Подробная инструкция и ограничения: [НАЧАТЬ.md](НАЧАТЬ.md).

## Android

Исходники в `android`, установка — APK из `dist` после локальной сборки.
Новый интерфейс: зелёный глобус, панели, быстрые команды, прокрутка и настройки двух ИИ.
Android 8.0 и новее. Фоновое прослушивание не реализовано.
Локальный APK подписан отладочным ключом этого компьютера. Его подпись может отличаться от прежнего APK из GitHub; обновление поверх прежней установки в таком случае не пройдёт.

## Проверка

- Windows: `python -m pytest -q` (pytest устанавливается отдельно).
- Android: Gradle 9.8.1, JDK 17+, Android SDK; `gradle -p android :app:testDebugUnitTest :app:assembleDebug`.
- На Windows собирайте Android из пути без кириллицы, например отдельной временной папки.

Ответы через настоящие API требуют пользовательских ключей. Автотесты адаптеров не заменяют эту проверку.
