# Голосовой ассистент Kartal

Ассистент для Windows, который понимает русский, узбекский и турецкий, открывает
программы и сайты и отвечает голосом. На любые другие вопросы отвечает Claude и,
когда нужно, сам ищет свежую информацию в интернете (курсы, биржа, новости, погода).

## Что умеет

| Скажите | Что произойдёт |
|---|---|
| «Картал, открой Телеграм» | откроется Telegram (если его нет, то веб-версия) |
| «Картал, открой ватсап» | откроется WhatsApp или web.whatsapp.com |
| «Картал, открой ютуб» | откроется YouTube |
| «Картал, открой Spotify» (любая программа) | ищет ярлык в меню «Пуск» и на рабочем столе и запускает его |
| «Картал, найди на ютубе рецепт плова» | поиск на YouTube |
| «Картал, найди погоду в Алматы» | поиск в Google |
| «Картал, который час» / «какое сегодня число» | ответит голосом |
| «Картал, почему небо голубое?» | ответ от Claude (он помнит последние 10 вопросов) |
| «Картал, сколько стоит биткоин?» / «какой курс доллара к суму?» | Claude найдёт свежие данные в интернете и ответит голосом |
| «Картал, говори по-узбекски» / «по-турецки» / «по-русски» | сменить язык |
| «Картал, забудь разговор» | начать разговор с Claude заново |
| «Картал, стоп» | выключить ассистента |

Можно сказать просто «Картал», дождаться ответа «Слушаю» и потом сказать команду.

## Языки

Ассистент слушает на одном языке за раз (так точнее работает распознавание).
Язык при запуске задаётся в `config.json` (`"language": "ru"`, `"uz"` или `"tr"`)
или параметром `--lang uz`. Сменить язык можно голосом в любой момент:

| Язык | Сменить | Примеры команд |
|---|---|---|
| Русский | «говори по-русски», «ruscha gapir», «rusça konuş» | «открой телеграм», «найди на ютубе музыку», «который час» |
| Узбекский | «говори по-узбекски», «o'zbekcha gapir» | «Telegramni och», «YouTube'da musiqa qidir», «dollar kursini qidir», «soat necha», «xayr» |
| Турецкий | «говори по-турецки», «türkçe konuş» | «Telegram'ı aç», «YouTube'da Tarkan aç», «bitcoin fiyatını ara», «saat kaç», «dur» |

Claude отвечает на том языке, на котором задан вопрос.

Ассистент говорит нейроголосами Microsoft (пакет `edge-tts`, нужен интернет): они звучат
как живой человек, и есть настоящий узбекский голос. В `config.json` в разделе `voice`
можно выбрать `"gender": "female"` для женского голоса и скорость `"edge_rate": "+10%"`.
Если интернета нет или пакет не установлен, ассистент говорит голосом Windows
(`"engine": "windows"` включает его всегда).

### Управление компьютером, экран и память

Claude сам понимает просьбы на любом из трёх языков и выполняет их на компьютере:
«сделай погромче», «поставь на паузу», «следующая песня», «открой загрузки»,
«найди файл отчёт и открой», «заблокируй компьютер», «выключи компьютер»
(сначала переспросит, выключит через минуту, «отмена» останавливает),
«что у меня на экране?», «прочитай ошибку на экране».

Ассистент помнит последние 10 вопросов и ответов и после перезапуска, а на просьбу
«запомни, что…» сохраняет факт навсегда («забудь про…» удаляет). Всё хранится в
`memory.json` рядом с программой; «новый разговор» очищает разговор (факты остаются). Выключить управление
компьютером можно так: `"pc_control": false` в разделе `claude` файла `config.json`.

Ответ Claude приходит потоком: ассистент начинает говорить первое предложение, пока
остальные ещё пишутся, и заранее готовит звук следующего предложения.

## Установка (Windows)

1. Установите [Python 3.10 или новее](https://www.python.org/downloads/) и при установке
   отметьте галочку **Add Python to PATH**.
2. Скачайте этот репозиторий и откройте папку с ним в терминале (PowerShell).
3. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и вставьте свой ключ Claude API
   (получить его можно на https://console.anthropic.com):

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

   Без ключа всё, кроме ответов на вопросы, тоже работает.

## Запуск

```powershell
python -m assistant.main
```

Или просто дважды щёлкните по файлу **Запуск.bat**.

Откроется пульт в стиле Джарвиса. В центре вращается светящийся глобус: голубой,
когда ассистент ждёт, ярче, когда слушает, оранжевый, когда думает, и с волной,
когда говорит. Вокруг панели:

- **Живая лента** — что вы сказали и что ответил ассистент.
- **Быстрые команды** — Telegram, WhatsApp, YouTube, курс доллара, биткоин, новости одним щелчком.
- **Строка внизу** — напишите команду и нажмите Enter; обращаться по имени не нужно.
- **Кнопка микрофона** — нажмите и говорите без слова «Kartal».
- **Компьютер** — загрузка процессора, памяти, диска и заряд батареи.
- **Биржа** — биткоин, эфир, S&P 500, золото и курс доллара к суму, рублю и лире
  (обновляется раз в две минуты, без ключей).
- **Ядро ИИ** — подключён ли Claude, язык, память разговора.

По всему окну идёт движение: плывёт сетка фона с искрами, по рамкам панелей
бегут огоньки, сверху вниз проходит луч сканера.

Цвет меняется в `config.json`: `"theme": "green"` — тёмно-зелёный, красный когда думает и синий когда говорит,
`"theme": "blue"` — голубой. F11 открывает пульт на весь экран. Старое маленькое окно с кольцами включается
в `config.json`: `"style": "compact"` в разделе `ui`. Запустить без окна можно
параметром `--no-ui` или `"enabled": false`.

Без микрофона, чтобы попробовать команды текстом:

```powershell
python -m assistant.main --text
```

Для распознавания речи нужен интернет (используется бесплатный сервис Google).

## Как переименовать ассистента

Откройте `config.json` и поменяйте имя и слова, на которые он откликается:

```json
"name": "Пятница",
"wake_words": ["пятница"],
```

Пишите в `wake_words` имя так, как его услышит распознавание речи (обычно по-русски).
Если хотите, чтобы ассистент выполнял всё сказанное без обращения по имени,
поставьте `"require_wake_word": false`.

## Как добавить свою программу

Добавьте запись в раздел `apps` файла `config.json`. Подойдёт один из способов запуска:

```json
"steam": {
  "aliases": ["стим", "steam"],
  "path": "C:\\Program Files (x86)\\Steam\\steam.exe"
},
"почта": {
  "aliases": ["почта", "gmail"],
  "url": "https://mail.google.com"
}
```

- `path` открывает файл программы;
- `url` открывает сайт в браузере;
- `uri` открывает ссылку приложения (например `tg://`), а `fallback_url` используется, если приложение не установлено;
- `command` выполняет команду Windows (например `notepad`).

Большинство установленных программ находятся и без этого, по ярлыкам в меню «Пуск».

## Настройки Claude

В разделе `claude` файла `config.json`:

- `model` — модель, по умолчанию `claude-opus-5-5`;
- `effort` — `low` отвечает быстрее, `high` думает дольше;
- `web_search` — разрешить поиск в интернете (`true`/`false`);
- `max_searches` — сколько поисков можно сделать на один вопрос;
- `history_turns` — сколько последних вопросов помнить.

Поиск в интернете оплачивается отдельно от ответов (по тарифам Anthropic за каждый
поиск), поэтому если хочется экономить, уменьшите `max_searches` или выключите `web_search`.
Ассистент сообщает цифры с биржи, но не советует, что покупать или продавать.

## Структура

- `assistant/main.py` — главный цикл: слушать, понять, выполнить, ответить
- `assistant/commands.py` — разбор фразы в команду
- `assistant/apps.py` — открытие программ, сайтов и поиска
- `assistant/brain.py` — ответы через Claude API
- `assistant/speech.py` — микрофон и голос
- `assistant/pc_tools.py`, `assistant/memory.py` — управление компьютером, снимок экрана и память
- `assistant/speech_text.py` — очистка текста для чтения и нарезка ответа на предложения
- `assistant/dashboard.py` — пульт с глобусом и панелями
- `assistant/ui.py` — маленькое окно с кольцами и связь окна с ассистентом
- `assistant/sysinfo.py`, `assistant/markets.py` — данные для панелей «Компьютер» и «Биржа»
- `assistant/i18n.py` — фразы ассистента на трёх языках
- `config.json` — имя, программы и настройки

## Версия для Android

Код телефонного приложения лежит в папке `android/`. Его собирает GitHub
(workflow «Android APK»), готовый файл всегда можно скачать по ссылке:

https://github.com/Torebay/torebay/releases/latest/download/Kartal.apk

Как установить:

1. Откройте ссылку на телефоне и скачайте `Kartal.apk`.
2. Откройте скачанный файл. Если телефон спросит, разрешите установку из этого источника.
3. Запустите Kartal, разрешите микрофон и вставьте ключ Claude API в настройках (значок ⚙).

Нажмите на кольцо и говорите. В настройках можно включить «Слушать всегда»: тогда
приложение, пока оно открыто, само слушает и откликается на имя («Картал, …»).
Внизу экрана можно писать команды текстом.
