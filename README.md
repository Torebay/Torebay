# Голосовой ассистент (Jarvis)

Ассистент для Windows, который понимает русский, узбекский и турецкий, открывает
программы и сайты и отвечает голосом. На любые другие вопросы отвечает Claude и,
когда нужно, сам ищет свежую информацию в интернете (курсы, биржа, новости, погода).

## Что умеет

| Скажите | Что произойдёт |
|---|---|
| «Джарвис, открой Телеграм» | откроется Telegram (если его нет, то веб-версия) |
| «Джарвис, открой ватсап» | откроется WhatsApp или web.whatsapp.com |
| «Джарвис, открой ютуб» | откроется YouTube |
| «Джарвис, открой Spotify» (любая программа) | ищет ярлык в меню «Пуск» и на рабочем столе и запускает его |
| «Джарвис, найди на ютубе рецепт плова» | поиск на YouTube |
| «Джарвис, найди погоду в Алматы» | поиск в Google |
| «Джарвис, который час» / «какое сегодня число» | ответит голосом |
| «Джарвис, почему небо голубое?» | ответ от Claude (он помнит последние 10 вопросов) |
| «Джарвис, сколько стоит биткоин?» / «какой курс доллара к суму?» | Claude найдёт свежие данные в интернете и ответит голосом |
| «Джарвис, говори по-узбекски» / «по-турецки» / «по-русски» | сменить язык |
| «Джарвис, забудь разговор» | начать разговор с Claude заново |
| «Джарвис, стоп» | выключить ассистента |

Можно сказать просто «Джарвис», дождаться ответа «Слушаю» и потом сказать команду.

## Языки

Ассистент слушает на одном языке за раз (так точнее работает распознавание).
Язык при запуске задаётся в `config.json` (`"language": "ru"`, `"uz"` или `"tr"`)
или параметром `--lang uz`. Сменить язык можно голосом в любой момент:

| Язык | Сменить | Примеры команд |
|---|---|---|
| Русский | «говори по-русски», «ruscha gapir», «rusça konuş» | «открой телеграм», «найди на ютубе музыку», «который час» |
| Узбекский | «говори по-узбекски», «o'zbekcha gapir» | «Telegramni och», «YouTube'da musiqa qidir», «dollar kursini qidir», «soat necha», «xayr» |
| Турецкий | «говори по-турецки», «türkçe konuş» | «Telegram'ı aç», «YouTube'da Tarkan aç», «bitcoin fiyatını ara», «saat kaç», «dur» |

Claude отвечает на том языке, на котором задан вопрос.

Голос ответа берётся из Windows. Русский и турецкий голоса можно добавить в
«Параметры → Время и язык → Речь → Добавить голоса». Узбекского голоса в Windows
обычно нет, поэтому по-узбекски ассистент читает ответ турецким голосом.

## Установка (Windows)

1. Установите [Python 3.10 или новее](https://www.python.org/downloads/) и при установке
   отметьте галочку **Add Python to PATH**.
2. Скачайте этот репозиторий и откройте папку с ним в терминале (PowerShell).
3. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и вставьте свой ключ Claude API
   (получить его можно на https://console.anthropic.com):

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

   Без ключа всё, кроме ответов на вопросы, тоже работает.

## Запуск

```powershell
python -m assistant.main
```

Без микрофона, чтобы попробовать команды текстом:

```powershell
python -m assistant.main --text
```

Для распознавания речи нужен интернет (используется бесплатный сервис Google).

## Как переименовать ассистента

Откройте `config.json` и поменяйте имя и слова, на которые он откликается:

```json
"name": "Пятница",
"wake_words": ["пятница"],
```

Пишите в `wake_words` имя так, как его услышит распознавание речи (обычно по-русски).
Если хотите, чтобы ассистент выполнял всё сказанное без обращения по имени,
поставьте `"require_wake_word": false`.

## Как добавить свою программу

Добавьте запись в раздел `apps` файла `config.json`. Подойдёт один из способов запуска:

```json
"steam": {
  "aliases": ["стим", "steam"],
  "path": "C:\\Program Files (x86)\\Steam\\steam.exe"
},
"почта": {
  "aliases": ["почта", "gmail"],
  "url": "https://mail.google.com"
}
```

- `path` открывает файл программы;
- `url` открывает сайт в браузере;
- `uri` открывает ссылку приложения (например `tg://`), а `fallback_url` используется, если приложение не установлено;
- `command` выполняет команду Windows (например `notepad`).

Большинство установленных программ находятся и без этого, по ярлыкам в меню «Пуск».

## Настройки Claude

В разделе `claude` файла `config.json`:

- `model` — модель, по умолчанию `claude-opus-5-5`;
- `effort` — `low` отвечает быстрее, `high` думает дольше;
- `web_search` — разрешить поиск в интернете (`true`/`false`);
- `max_searches` — сколько поисков можно сделать на один вопрос;
- `history_turns` — сколько последних вопросов помнить.

Поиск в интернете оплачивается отдельно от ответов (по тарифам Anthropic за каждый
поиск), поэтому если хочется экономить, уменьшите `max_searches` или выключите `web_search`.
Ассистент сообщает цифры с биржи, но не советует, что покупать или продавать.

## Структура

- `assistant/main.py` — главный цикл: слушать, понять, выполнить, ответить
- `assistant/commands.py` — разбор фразы в команду
- `assistant/apps.py` — открытие программ, сайтов и поиска
- `assistant/brain.py` — ответы через Claude API
- `assistant/speech.py` — микрофон и голос
- `assistant/i18n.py` — фразы ассистента на трёх языках
- `config.json` — имя, программы и настройки
